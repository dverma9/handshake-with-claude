🧠 System Prompt Design

The tutor uses a carefully structured system prompt with these pillars:

  • Role + Personality: Defined as "LinguaPlay," a playful, encouraging tutor who uses emoji, gentle humor, and game mechanics (XP, streaks) to motivate learners.
  • Adaptive Level Detection: The prompt instructs the AI to infer proficiency from user responses and adjust vocabulary/complexity accordingly, even mid-session.
  • Structured Output Schema: Every response follows a predictable JSON schema: chat, corrections, exercise, vocab, xp. This allows the UI to render specialized components rather than raw text.
  • Edge-case Handling: Irrelevant input (off-topic) is gently redirected. Missing context (no topic chosen) defaults to general conversation. Abuse/inappropriate content triggers a friendly, firm refusal.

🎨 UI Design Choices

  • Dual-zone layout: Setup screen → app screen avoids a blank chatbot opening; context is set before any message is sent.
  • Color system: Purple = AI/tutor; Teal = positive/vocab; Coral = corrections; Gold = exercises. Each semantic color maps to a learning concept.
  • Inline correction blocks appear inside tutor bubbles rather than as separate messages — this keeps corrections contextual and non-intimidating.
  • XP bar + stats: Gamification elements are persistent in the header and stats row, reinforcing progress even in short sessions.
  • Quick prompts: Reduce blank-slate paralysis for new learners who don't know what to type first.

🚀 How to Extend It

  • Add memory: Store conversation history in localStorage, inject it as assistant context on each call to simulate long-term memory.
  • Add speech: Use the Web Speech API (SpeechSynthesis + SpeechRecognition) for voice input/output — especially powerful for pronunciation practice.
  • Add tools: Connect a dictionary API (e.g. Wiktionary) or image search to show visual vocabulary cards.
  • Multi-step flows: Add a "Lesson Mode" where the tutor runs a pre-scripted 5-step lesson using a step field in the response schema.
  • Leaderboard: Sync XP to a backend (e.g. Supabase) to build social streaks and language-group challenges.
